# Grounded Frontend

UI prototype for Grounded, built with Next.js App Router, TypeScript, Tailwind CSS, and shadcn-style component primitives.

## Commands

```bash
npm install
npm run dev
npm run build
```

The app uses mock product data first so the full route map, trust surfaces, workspace shell, mode gating, datasets, agents, runs, settings, and API key flows can be evaluated before backend wiring.
